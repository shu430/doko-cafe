# Phase1 タスク分解

## Summary

Phase1 は「徒歩ルート上でカフェを探せる最小機能」を作る。Google Maps は JavaScript API 中心で扱い、まずは画面上で入力、地図表示、徒歩ルート表示、カフェ一覧、Google Maps リンクまでをつなげる。

## Key Tasks

- **初期画面の置き換え**
  - `create-next-app` の初期画面を削除する
  - アプリ名、出発地入力、目的地入力、検索ボタンを持つ画面にする
  - Phase1 では移動手段は徒歩固定にする

- **Google Maps 表示**
  - Google Maps JavaScript API を読み込む
  - 地図を画面に表示する
  - API キーは環境変数で扱い、コードに直書きしない

- **徒歩ルート検索**
  - 出発地と目的地から徒歩ルートを取得する
  - 地図上にルートを描画する
  - 入力不足やルート取得失敗時のエラー表示を用意する

- **ルート周辺カフェ検索**
  - 徒歩ルート周辺のカフェを検索する
  - 検索結果を地図上にマーカー表示する
  - カフェ名、住所、評価など最低限の情報を一覧表示する

- **Google Maps リンク**
  - 各カフェに Google Maps で開くリンクを付ける
  - ルート検索結果からユーザーが外部の Google Maps に遷移できるようにする

- **構成整理**
  - UI は `components/`
  - Google Maps API 関連処理は `services/`
  - 型定義は `types/`
  - 定数は `constants/`
  - 純粋な補助関数は `utils/`
  - `any` は使わず TypeScript で型を付ける

## Test Plan

- `npm run lint` が通る
- `npm run build` が通る
- 出発地・目的地が未入力の場合に検索できない、またはエラーが出る
- 正常な出発地・目的地で徒歩ルートが地図に表示される
- ルート周辺のカフェ一覧が表示される
- カフェの Google Maps リンクが別タブで開く
- API キー未設定時にわかりやすいエラー表示になる

## Assumptions

- Phase1 の移動手段は徒歩のみ
- Google Maps は JavaScript API 中心で実装する
- 今回の分解は大項目中心で、Issue 化やファイル単位の詳細分解は次の段階で行う
- 既存実装は初期テンプレートのため、トップページは全面的に置き換える
